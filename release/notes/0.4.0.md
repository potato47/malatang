## 窗口置顶

- 升级 FIA 到 0.18.0，原生窗口标题栏在“在浏览器中打开”左侧增加置顶图标，开发、预览和正式版本一致。
- 点击“置顶窗口”后图标选中，当前窗口保持在当前桌面的普通窗口之上；再次点击“取消置顶”恢复。加载和后端重连期间仍可操作。
- 隐藏再显示、后端重连保留置顶状态；真正销毁窗口或退出应用后重置，不控制浏览器自身窗口或跨桌面。

## 升级方式

本次更换原生 Host，**请下载完整 DMG，退出旧应用后替换安装**；不能仅靠代码更新添加按钮。账号、模型配置、插件、KV 和历史保留。SDK 保持 0.2.1、manifest 保持 0.2，现有 SDK 0.2 插件无需为本次变更重建。
