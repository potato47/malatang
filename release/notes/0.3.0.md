## 新增与修复

- 标题栏最右侧新增“在浏览器中打开”，可在本机浏览器使用完整界面，与原生窗口共享模型、插件、KV 和持久数据。
- 浏览器使用当前实例、当前标签页的独立授权；60 秒单次链接，后端重启或更新后失效。应用及托盘菜单可断开所有浏览器连接。裸 IP 和端口不能调用受保护 API。
- 文件选择、剪贴板和窗口等原生能力按白名单开放；钥匙串、屏幕捕获、CLI 管理及退出等直接调用继续拒绝。开发版修复旧 Vite 缓存导致的原生桥连接失败，文件面板不再受默认 30 秒超时限制。
- 开发版 / 预览版增加 DEV / PREV 图标、菜单与窗口名称。`fia run` 使用独立预览数据目录，可与正式版并行运行。
- 主题浮层移至侧栏右侧并增加留白，选择框焦点边框更轻；内置 SDK 更新为 0.2.1，保持 manifest SDK 0.2 兼容。

## 升级方式

本版升级 FIA 原生运行时至 0.17.0，**必须下载完整 DMG，退出旧应用后替换安装**；不能通过前后端代码更新获得全部能力。账号、模型配置、插件、KV 和历史保留，未保存草稿不会跨重启保留。SDK 0.2 插件继续兼容；SDK 0.1 插件仍需按迁移指南重建。

插件仍按可信本地代码运行；浏览器授权不是插件沙箱。请勿分享授权链接。
