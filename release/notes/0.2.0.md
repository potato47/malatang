## 0.2.0 更新

- 宿主、内置插件和独立插件共享同一套组件、主题及弹层交互；插件业务样式改用 CSS Modules。
- 新增 `malatang plugin create/check/build/pack`，内置 notes / model 两种独立项目模板；项目自带 SDK 快照，开发者安装 Bun 后即可构建。
- 改善页面保留时的弹层关闭、焦点和资源清理，并修复等待系统钥匙串确认时可能提前启动超时的问题。

## 升级说明

本次更换 FIA 原生运行时，请下载完整 DMG 覆盖安装；用户模型、账号、KV 和历史数据保留。

插件契约升级为 SDK 0.2。旧 SDK 0.1 插件需迁移源码、重新构建并安装；宿主会给出明确提示。SDK 0.2.0 随 CLI 模板提供，npm 发布状态以 registry 为准。
