## 界面与主题

- 设置、译文、应用中心和笔记统一使用 Base UI 与 Tailwind CSS 4；更新模型搜索、菜单、对话框和反馈组件。
- 内容区增加默认、GitHub 和自定义配色，浅色 / 深色分别调整强调色、背景和文字，支持预览、取消与恢复默认；插件跟随宿主主题。原生标题栏仍跟随系统明暗模式。
- 原生置顶与浏览器按钮使用中性样式；修复浮层关闭、隐藏页面焦点、模型目录失效处理及中文输入期间快捷键误提交。

## ChatGPT 凭证

- 账号注册、当前账号及 access / refresh / ID token 改为数据目录内的 `chatgpt-auth.json`，不再触发系统钥匙串授权。普通模型 API Key 和设置继续保存在 `platform.json`。
- 凭证文件为明文；数据目录权限 0700、文件权限 0600，使用完整写入、同步及原子替换。不要分享该文件或包含它的备份。
- 旧钥匙串记录不读取、不迁移、不删除。**升级后需重新登录 ChatGPT，删除旧的未连接订阅模型，再从新账号目录添加模型。** 不自动重新绑定账号，避免误用计费身份。
- 空文件、损坏内容或初始化权限错误保留原文件并禁用 ChatGPT；普通保存失败保留旧状态，刷新 token 已消耗后无法保存则停止使用凭证。错误提示改为文件、目录权限及磁盘空间检查。

## 插件与开发

- SDK 0.3.0 使用组合式 Base UI API 和隔离的 Tailwind `p:` 样式，manifest 兼容版本为 `0.3`；CLI 的 notes / model 模板同步更新。
- **SDK 0.2 及更早插件不兼容新宿主，需更新组件 API、manifest 并重新构建安装。** 保持原插件 ID 可继续使用既有 KV 和历史；宿主不会自动升级独立插件。
- FIA 源码迁入 `framework/fia/`，从同一提交构建框架与应用，开发时自动重建 / 重启框架；源码维护需要 Bun 1.4.3 和 Swift 6。FIA 独立 npm 发布暂停，现有公开 0.18.0 包不等同共仓源码。
- 内置 Bun 升级至 1.4.3；使用正式安装包无需另外安装 Bun 或 Swift。

## 升级方式

本次更换原生 Host 和 Bun，**请下载完整 DMG，退出旧应用后替换安装**；不能只安装代码更新。普通 API Key、模型配置、插件记录、KV、外观和历史保留，ChatGPT 登录与旧插件按上述要求重新配置。未保存页面状态不跨重启恢复。

应用版本为 0.4.1 / build 5；SDK 独立版本为 0.3.0，应用发行与 SDK npm 发布分别验收。跨版本代码热更新未实测，真实账号的新 OAuth / token 刷新不以自动化 fixtures 视为已验收。
